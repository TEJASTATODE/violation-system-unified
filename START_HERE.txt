⚙️ KEY IMPROVEMENTS
═══════════════════════════════════════════════════════════════════════════

✨ Trajectory Consistency (0.0-1.0)
   → Detects turning vehicles (< 0.6 = turning)
   → Prevents false positives

✨ Speed Stability (0.0-1.0)
   → Detects parking/erratic movement
   → Ignores cars backing up or adjusting position

✨ Turn Grace Period (3 frames)
   → Allows vehicles 3 frames to turn
   → No false positives from lane changes

✨ Multi-frame Validation
   → Requires 5+ consecutive frames of wrong behavior
   → Not just instant detection
